# Conributing: 
This repository contains code to perform analysis and generate
figures related to ozone foliar injury monitoring at parks in the Cumberland
Piedmont Network. Changes that improve the utility of this repository are
encouraged. You are free to submit a pull request, or you can submit an issue [here](https://github.com/DOI-NPS/OzoneFoliarInjuryCUPN/issues)

## Contributing Requirements: 
Make sure your Pull Request is net-neutral for test coverage.  PRs that decrease test coverage will not be
merged. As current test coverage is 0%, this should be a low bar.
